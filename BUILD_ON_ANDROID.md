# Как получить APK только с телефона

Самый простой путь — GitHub Actions. Компьютер не нужен.

## 1. Создай аккаунт GitHub
Открой https://github.com/ и войди или зарегистрируйся.

## 2. Создай новый репозиторий
- Нажми `+` → `New repository`.
- Назови, например, `NovaSpaceLauncher`.
- Можно выбрать `Public`.
- Нажми `Create repository`.

## 3. Загрузить проект
На странице репозитория:
- `Add file` → `Upload files`.
- Распакуй ZIP на телефоне.
- Загрузи ВСЕ файлы и папки проекта, включая `.github/workflows/build-apk.yml`.
- Нажми `Commit changes`.

## 4. Запустить сборку
Открой вкладку `Actions`.
Выбери `Build NovaSpace APK`.
Нажми `Run workflow` → `Run workflow`.

После окончания появится зелёная галочка.

## 5. Скачать APK
Открой завершённый запуск workflow.
Внизу страницы найди `Artifacts`.
Нажми `NovaSpace-debug-apk`.
Скачается ZIP с `app-debug.apk`.
Распакуй его на телефоне.

## 6. Установка
Открой `app-debug.apk`.
Если Android попросит разрешить установку из этого источника — разреши для приложения, через которое открываешь APK, затем повтори установку.

После установки открой NovaSpace. Android может предложить выбрать приложение по умолчанию для кнопки Home — выбери NovaSpace, если хочешь использовать его как основной лаунчер.

## Важно
Это DEBUG APK для личного тестирования. Android требует, чтобы APK был подписан; debug-сборка подписывается автоматически ключом от build-системы. Для публикации полноценной release-версии понадобится отдельный ключ подписи.

GitHub Actions автоматически собирает APK и сохраняет его как artifact.
